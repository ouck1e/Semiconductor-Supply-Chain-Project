    Open paper trades

    Decisions made on dates after the agents' training cutoff, using real stock names and today's news. They stay open until enough later prices exist to score them.

    Start a paper trade

    1. Make a packet for a stock on the latest trading day:python agent_packets.py --ticker MU --date --named
    2. Run the six agents on it (by hand in Claude chats, following 00_HOW_TO_RUN.txt), saving strategist.txt and boss.txt.
    3. Score it: python agent_score.py <run_id>. It stays pending and appears here.
    4. As new prices arrive, close it with python agent_score.py --update, then rebuild this page with run_dashboard.bat.
    Research on how markets react to supply shocks, not investment advice. Simulated fills at daily closes with . Data: dashboard/data.json, built by agent_dashboard.py from data/agents/ and data/market/market.db.
