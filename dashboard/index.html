    Give the agents a stock and a period, and they trade through it: a full six-agent decision every week while they hold nothing, exits on each trade's stop, target or time limit.

    1. See the plan and cost (spends nothing): python agent_span.py --ticker MU --start 2022-01-03 --end 2022-03-31
    2. Run it yourself in Claude chats, free: add --manual. Each agent's prompt goes onto your clipboard; paste it into a new chat, copy the reply, press Enter. Type q to stop and --resume later.
    3. Or run it with the Claude API (paid): add --yes (needs ANTHROPIC_API_KEY). Or try a free demo with a simple rule: add --demo.
    4. Rebuild this page with run_dashboard.bat.
